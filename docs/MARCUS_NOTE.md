# A Monday note for Marcus

This dashboard shows how ChatGPT, Perplexity, and Google's AI Overviews describe Corvane Fleet
across the selected buyer questions. It compares Corvane with Trakvia, Routelyne, and Gridwell,
shows which questions and answers explain movement, and flags claims that conflict with the
approved facts file.

The main number is a 0–100 visibility score for the observed answer panel. It gives credit when a
company is mentioned, more credit when it appears earlier, and adjusts for whether the answer
recommends or criticizes it. Prompt importance also affects the average. Every tracked competitor
uses the same calculation. The method is simple and repeatable because the data contains only two
runs per question and engine; it is a useful product measure, not a market-share estimate.

Check the coverage warning before interpreting a change. A partial week is not compared as though
missing answers were negative. The dashboard labels a comparison to an earlier complete week
separately. A movement beyond the observed run-variation threshold is a reason to investigate, not
proof of a statistically certain change.

When you see a wrong-fact alert, open its linked answer and confirm the claim against the approved
facts before asking anyone to correct content. Each Monday, review the latest score and coverage,
compare competitors, inspect the largest question/engine drivers, check wrong-fact alerts, and open
important changed answers in Answer Explorer. Treat unsupported claims as unverified, not false.
